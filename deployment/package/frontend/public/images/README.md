# Hackmitten 3.0 Static Images

Place production website assets in these folders:

- branding/       College logo, Hackmitten logo, QR/brand assets
- coordinators/   Coordinator portraits
- gallery/        Public event gallery photos
- sponsors/       Sponsor logos
- winners/        Winning team photos

Use stable filenames with lowercase letters, numbers, and hyphens.

Examples:

coordinators/manasa-m-swamy.jpg
gallery/hackmitten-2025-01.jpg
sponsors/example-sponsor.png
winners/team-alpha.jpg
